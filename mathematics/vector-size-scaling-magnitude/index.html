Foundation idea

Scalar multiplication changes the magnitude of a vector.

If |k| > 1, the vector becomes longer. If 0 < |k| < 1, it becomes shorter. A positive scalar keeps the same direction. A negative scalar reverses the direction.

In particular, −1a = −a: same magnitude, opposite direction.

Foundation idea

A vector's position does not determine its magnitude.

Moving the same vector somewhere else on the coordinate plane does not change its length or direction. First find the horizontal and vertical changes using Finish − Start. Those changes form the sides of a right-angled triangle, and the vector is its hypotenuse.

A component may be negative because it describes direction. Magnitude is a length, so it cannot be negative.

Reverse the vector and compare: the signs of the components change, but the magnitude does not. For the starting example, AB = (3, 4), BA = (−3, −4), and |AB| = |BA| = 5.

Unit Vectors

A unit vector keeps the direction of a vector but gives it a magnitude of exactly 1.

Why do we want a unit vector?

Sometimes we want the direction of a vector without keeping its original magnitude. Once we have a vector of length 1 in the required direction, we can scale it to any magnitude we need.

4. Why scale a unit vector?

A unit vector gives us a direction, but in a real situation we often need a vector with both a particular direction and a particular magnitude.

For example, we might know:

  • the direction an object needs to move, but want to choose its speed;
  • the direction of a force, but need the force to have a particular size; or
  • the direction of travel, but want a particular displacement.

The unit vector gives us the direction. Scaling it gives us the magnitude we need.

Foundation idea

Scalar multiplication changes the size of a vector. Magnitude tells us its size. A unit vector keeps the direction but standardises the magnitude to 1, so we can then scale it to whatever magnitude we need.

Important: the zero vector has magnitude 0, so it cannot be converted into a unit vector because division by 0 is undefined.
