Vector Notation

One vector can be represented in several different ways.

A vector describes a movement with both magnitude and direction. The notation may change, but the vector itself does not.
A = starting positionB = finishing positionDashed lines = horizontal and vertical change

Select each form to see what the notation tells us.

A position is not a vector

A = (1, 1) tells us where point A is.

AB = 43 tells us how to move from A to B: 4 units right and 3 units up.

Direction can be negative. Magnitude cannot.

A vector can have negative components because it may point left or down.

−4−3means 4 units left and 3 units down.

The magnitude (size) of a vector is a distance. It is therefore always positive, except for the zero vector, which has magnitude 0.

We will learn how to calculate magnitude later. For now, remember: components tell us direction as well as movement; magnitude tells us size.

The rule now has a reason

To find the vector from a starting point to a finishing point, calculate the change in each coordinate.

AB = B − A = xB − xAyB − yA

Finish − Start. This is not a separate trick to memorise. It is exactly the horizontal and vertical movement shown on the diagram.

What vector addition means

If one vector takes us from A to B, and the next takes us from B to C, their combined movement takes us directly from A to C.

AB + BC = AC

That is why we add corresponding components. We are combining the total horizontal movement and the total vertical movement.

Vector Subtraction

Subtracting a vector means adding its opposite.

The key idea: a − b = a + (−b). The vector −b has the same magnitude as b, but points in the opposite direction.

What vector subtraction means

We do not need a completely new operation for vector subtraction. Instead, reverse the vector being subtracted and then add it.

a − b = a + (−b)

Changing b to −b reverses every component. Then add corresponding components exactly as you did for vector addition.
